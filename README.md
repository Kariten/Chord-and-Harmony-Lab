# Chord & Harmony Lab

一个面向键盘手的和声分析与创作参考网页。它可以展示常见调式/调性的各级和弦，播放对应和弦听感，并用可点击钢琴键盘高亮展示和弦构成与自动识别所选音符。

## 运行

```bash
npm start
```

然后打开：

```text
http://localhost:4173
```

也可以用任意静态文件服务器打开项目根目录。

## 测试

```bash
npm test
```

测试覆盖：

- C 大调七和弦级数生成
- A 和声小调七和弦级数生成
- 转位 slash chord 识别
- C6 / Am7 等等和弦别名
- 常见扩展和变化属和弦识别
- 音名与调式音阶工具函数

## 使用说明

1. 在顶部选择主音和调式，页面会自动生成该调式的 I-VII 级和弦。
2. 切换“三和弦 / 七和弦”查看不同层级的级数和声。
3. 点击任一级数卡片，钢琴会高亮该和弦的所有构成音，右侧显示根音、音程结构和别名。
4. 点击卡片上的 `Play` 可试听单个和弦，点击 `播放级数` 可顺序试听整组级数和弦。
5. 在底部钢琴上点选任意若干琴键，右侧会自动识别和弦名；如果有多种解释，会列出别名或可补音建议。
6. 点击 `播放所选` 试听当前手动选键；点击 `清空选键` 回到级数和弦展示。

## MIDI 键盘

1. 使用 Chrome、Edge 等支持 Web MIDI 的浏览器打开本地页面。
2. 接入 MIDI 键盘后点击顶部的 `启用 MIDI`，浏览器会请求 MIDI 设备权限。
3. 在 `MIDI 输入` 下拉框中选择设备；如果只有一个输入，页面会自动选中它。
4. 按下 MIDI 键盘上的若干音，右侧会实时显示当前输入音符构成的和弦名称、别名和音程结构。
5. MIDI 正在按下的键会在钢琴上以紫色高亮；识别出的根音仍以黄色高亮。
6. 松开所有 MIDI 键后，页面会回到手动选键或当前级数和弦展示。

Web MIDI 通常要求页面运行在安全上下文中；本项目的 `http://localhost:4173` 属于浏览器允许的本地安全场景。

## 和声范围

内置调式包含 Ionian、大调自然小调、和声小调、旋律小调、Dorian、Phrygian、Lydian、Mixolydian、Locrian 与和声大调。和弦识别覆盖常见三和弦、sus、六和弦、七和弦、半减/全减、add9、9、11、13、Lydian major、b9/#9/#5/b5 与 altered dominant 等键盘手常用结构。
