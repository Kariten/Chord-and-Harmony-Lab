# Chord & Harmony Lab

面向键盘手的和声分析、和弦识别与创作参考网页。页面支持调式各级和弦、交互式钢琴、MIDI 输入、吉他指法参考、和弦试听织体，以及可拖拽的和弦进行编排。

## 运行

```bash
npm start
```

浏览器打开：

```text
http://localhost:4173
```

同一局域网中的设备可以通过电脑的局域网 IP 和端口 `4173` 访问。

## 测试

```bash
npm test
```

测试覆盖和弦生成与拼写、和弦识别、试听织体、MIDI、吉他指法、多语言字典，以及和弦进行的 T/S/D 分类、排序和持久化数据校验。

## 基本使用

1. 在“各级和弦”模块选择主音、调式和三和弦/七和弦。
2. 点击和弦卡片可查看构成音、别名与吉他指法；点击“试听”可使用当前织体播放。
3. 在钢琴上点选琴键或接入 MIDI 键盘，右侧会实时识别和弦。
4. 顶部齿轮按钮打开全局设置，可切换语言、试听织体、BPM、吉他指法和 MIDI 输入。BPM 范围为 40–240，所有和弦试听、级数播放与队列播放都会使用当前速度；“五音 + 休止”系列织体会以低音根音持续支撑整小节，上方演奏五个八分音符后保留三个无新触发的拍点。
5. “播放级数”会按当前织体连续播放该调式的全部级数和弦。

## 钢琴音源

和弦与琴键试听使用 Salamander Grand Piano 的 Yamaha C5 实录采样，并通过最近采样移调覆盖完整 88 键音域。采样加载失败时会自动切换至内置合成音色，避免影响基础功能。音源采用 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) 许可，详细署名见 [`assets/piano/salamander/ATTRIBUTION.md`](assets/piano/salamander/ATTRIBUTION.md)。

## 和弦进行编排

1. 点击任意级数和弦卡片右上角的 `+`，将该和弦加入顶部队列。
2. 手动选键或 MIDI 输入识别出完整和弦后，点击识别结果右侧的 `+`，可保留实际输入音高与转位加入队列。
3. 队列标签使用边框和底色标示和声功能：
   - `T`：主功能组，包含 I、iii、vi。
   - `S`：下属功能组，包含 ii、IV。
   - `D`：属功能组，包含 V、vii。
   - `N`：当前调式中无法归类的和弦。
4. 直接拖动和弦标签改变顺序。支持鼠标拖动与触摸屏拖动。
5. 点击标签右侧 `×` 删除单个和弦，点击“清空”删除整个队列。
6. 点击“播放进行”，队列会使用当前织体连续播放；每个和弦按完整小节推进，钢琴同步高亮实际音区与根音。
7. 队列会自动保存到浏览器本地存储，刷新页面后仍会保留。

## MIDI 键盘

1. 使用支持 Web MIDI 的桌面浏览器打开页面。
2. 接入 MIDI 键盘，在齿轮设置中点击“启用 MIDI”。
3. 从 MIDI 输入列表选择设备；若只有一个输入，页面会自动选择。
4. 按下的 MIDI 音符会在钢琴上高亮，并实时更新和弦识别结果。

iPad Safari 当前不提供网页所需的 Web MIDI 接口，页面会显示“当前设备不支持 MIDI”，其他功能不受影响。

## 内置范围

调式包含 Ionian、Aeolian、Harmonic Minor、Melodic Minor、Dorian、Phrygian、Lydian、Mixolydian、Locrian 与 Harmonic Major。和弦识别覆盖常见三和弦、sus、六和弦、七和弦、减和弦、扩展和弦与 altered dominant 等键盘常用结构。
